Food Delivery Sales Analysis using SQL
Project Overview

This project analyzes food delivery data using SQL to understand customer behavior, restaurant performance, orders, revenue, and payment methods.

The analysis was performed using SQL queries to extract meaningful business insights from customer, restaurant, and order data.

Objectives
Analyze customer ordering behavior.
Identify top-performing restaurants.
Analyze revenue and customer spending.
Understand order patterns and payment methods.
Compare restaurant and customer performance.
Generate useful business insights using SQL.
